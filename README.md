# GeoReportes 📍

Aplicación móvil nativa para Android desarrollada en **Kotlin** y **Jetpack Compose** bajo el patrón arquitectónico **MVVM**. Permite registrar reportes ciudadanos con geolocalización en tiempo real.

## Tecnologías utilizadas
* **Lenguaje:** Kotlin
* **Interfaz de usuario:** Jetpack Compose (Material 3)
* **Arquitectura:** MVVM (`ViewModel` + `StateFlow`)
* **Sensor:** GPS (`FusedLocationProviderClient`)
* **Base de datos en tiempo real:** Firebase Cloud Firestore
